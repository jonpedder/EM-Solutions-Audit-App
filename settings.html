Emergency Management Audit Monitor

The monitor provides authorized users with a read-only view of Emergency Management feature-service changes recorded by the scheduled audit Notebook and ArcGIS Workflow Manager.

Authoritative record: the private hosted audit service and associated Workflow Manager jobs remain the systems of record.
Signing in
  1. Open the Audit Monitor and select Sign in.
  2. Use an authorized Public Safety ArcGIS Online account.
  3. Confirm your username appears in the header before reviewing private records.

If authentication expires, sign out and sign in again. Never copy access tokens into support requests.

Filtering and reviewing changes
  1. Choose a UTC start and end date.
  2. Optionally filter by emergency operation, service, or change type.
  3. Select Apply to query the audit service.
  4. Select a row to open event details and locate the current source feature when available.

Changed fields are presented as separate Before and After values. The exact JSON remains available in source exports.

Map and geometry changes

The Feature Locator resolves the selected record's current source feature. For non-delete events, this may differ from the feature geometry at the event timestamp.

  • POINT movement anchors are exact coordinates.
  • EXTENT_CENTER represents the movement of a line, polygon, multipoint, or extent envelope center.
  • Deleted features cannot be resolved from the current source layer.
Do not interpret current geometry as historical geometry. Always use the event timestamp and movement label when reviewing an incident.
Exports and records handling

Use CSV above the audit ledger to export every row matching the current filters. The export includes human-readable changed fields, movement coordinates, event IDs, Workflow Manager job IDs, timestamps, and editor attribution.

Use PDF report to generate a formatted audit-trail report with the active filters, summary totals, event details, before/after values, geometry movement, generation time, and page numbers.

Follow organizational records-retention and information-handling policies. Do not distribute private service URLs or audit extracts to unauthorized recipients.

UnauthorizedSign out and sign in with an account that can access the private control service and Web Map.
Feature cannot be mappedThe feature may have been deleted, moved, or become inaccessible. The audit row remains valid.
Slow resultsUse a shorter date window or reduce rows per request in Settings.
Settings

Settings are stored locally in the browser. Save changes, then return to the Audit Monitor or reload an open monitor tab.

  • Reset defaults restores the supported baseline.
  • Export JSON downloads a portable settings file.
  • Import JSON validates a settings file before saving it locally.

Settings cannot change OAuth registration, portal permissions, service schema, Notebook schedules, or Workflow Manager configuration.
